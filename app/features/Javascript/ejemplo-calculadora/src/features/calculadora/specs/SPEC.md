# Calculadora de práctica

Crear un proyecto independiente en Javascript/ejemplo-calculadora siguiendo el ejemplo de clase: React, Vite, JavaScript, useState, un hook y componentes conectados por props.

- Dos inputs controlados permiten números positivos, negativos y decimales.
- El componente padre comparte valores y acciones con los componentes hijos.
- El hook maneja cambios, suma, resta, multiplicación, división y limpieza.
- Los campos vacíos o números no finitos muestran un error; dividir entre cero también.
- Cambiar una entrada borra el resultado anterior y el error.
- Limpiar restaura las entradas y el resultado iniciales.
- La interfaz tiene etiquetas, foco visible y distribución adaptable.

Se conserva la estructura didáctica solicitada, sin introducir Redux, TypeScript o dependencias adicionales. Verificar lint y build.
